# Проект project_3

## Описание проекта:

Проект project_3 - создан как учебный, с работы HTML-кодом с помощью Bootstrap ,для написания простого веб-приложения.

##  Установка

1. Клонируйте репозиторий:
```
git@github.com:olgakostenko240/project_3.git
```
2. Установите зависимости:
```
poetry install
```

## Использование:

1. Создана Главная страница в файле home.html.
2. Создана страница Категория 1 в файле category.html.
3. Создана страница Каталог в файле catalog.html.
4. Создана страница Контакты в файле contacts.html.
5. Создан специальный класс MyServer, который отвечает за обработку входящих запросов от клиентов.
